## Phase 3 topology and index reference

`src/modules/landmarkTopology.ts` retains the official FACE_OVAL edges and reconstructs triangles from the tessellation edges exported by the pinned Apache-2.0 MediaPipe package. The unit test compares these with the installed package (36 oval connections, 852 triangles). Copyright 2020 The MediaPipe Authors; the Apache license above applies. No reference/template vertices are substituted for detected coordinates.

`tests/reference/canonical_face_model.obj` is an unmodified index-verification reference from [the official repository](https://raw.githubusercontent.com/google-ai-edge/mediapipe/master/mediapipe/modules/face_geometry/data/canonical_face_model.obj), retrieved 2026-10-18, under the repository Apache-2.0 license. SHA-256: `8bac80443397e113f41a8b565ea72c59390bc031d9defab289dba7bc0c54e618`. Its 468 vertices are used only in developer tests to check index membership and selected paired positions; the file is not served by the production app or used for photo measurements. MediaPipe's [coordinate definition](https://developers.google.com/edge/api/mediapipe/js/tasks-vision.normalizedlandmark) documents normalized x/y and relative z scale. FaceFrame's contour selections and shape thresholds are application choices, not Google-endorsed anatomical measurements or classifications.
